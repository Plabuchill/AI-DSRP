# Acceptance Criteria — Outbreak Dashboard (prototypes/v1) — test-docs/v1

อ้างอิงจาก `prototypes/v1/BUILD-PLAN.md` และการอ่านโค้ดจริงใน `prototypes/v1/index.html` / `prototypes/v1/script.js` เนื่องจากยังไม่มี Requirement/Backlog ID อย่างเป็นทางการ เอกสารนี้ตั้ง Feature ID เอง (FR-DASH-01 ถึง FR-DASH-06) ตาม 6 ส่วนของ UI ที่ยืนยันไว้ในแผน

## FR-DASH-01 — Navigation (Left Rail)

**Given** ผู้ใช้เปิดหน้า Outbreak Dashboard ครั้งแรก
**When** ผู้ใช้มองไปที่แถบเมนูซ้าย (left rail)
**Then** ต้องเห็น wordmark "ai-dsrp", หน้า Dashboard ต้องถูกทำเครื่องหมายว่าเป็นหน้าที่ active อยู่ และเมนู Cases/Alerts/Reports ต้องแสดงเป็น placeholder ที่ปิดใช้งาน (ไม่สามารถคลิกนำทางได้)

- [ ] Wordmark "ai-dsrp" แสดงที่ด้านบนของ left rail
- [ ] เมนู "Dashboard" มี state active แตกต่างจากเมนูอื่นอย่างชัดเจน
- [ ] เมนู Cases / Alerts / Reports แสดง badge "SOON" และ aria-disabled="true" คลิกแล้วไม่มีการนำทางใดๆ เกิดขึ้น
- [ ] บนหน้าจอ tablet (≤960px) left rail ยุบเหลือ icon-only (short mark "ai") โดยไม่กระทบการใช้งานเมนู Dashboard

## FR-DASH-02 — KPI Cards

**Given** ผู้ใช้อยู่ที่หน้า Outbreak Dashboard ที่มี mock data ครบทุกภูมิภาค/โรค
**When** หน้าโหลดเสร็จ (ค่าเริ่มต้น: ทุกโรค/ทุกภูมิภาค/14 วัน) หรือผู้ใช้เปลี่ยน filter ใดๆ
**Then** KPI ทั้ง 4 การ์ด (Total Active Cases, New Cases Today, Active Outbreak Zones, Overall Risk Level) ต้องแสดงค่าที่คำนวณจากข้อมูลที่ตรงกับ filter ปัจจุบันเสมอ ไม่ค้างค่าเดิมหรือแสดง "--"

- [ ] ทั้ง 4 KPI แสดงค่าตัวเลข/ข้อความจริงหลังโหลดหน้า (ไม่ใช่ "--")
- [ ] Active Outbreak Zones เท่ากับจำนวนภูมิภาคที่มีสถานะ "เฝ้าระวัง" หรือ "วิกฤต" ใน Region Risk Grid พอดี
- [ ] Overall Risk Level แสดงระดับความเสี่ยงสูงสุด (worst-case) ในบรรดาภูมิภาคที่กำลังแสดงผลอยู่
- [ ] เมื่อเปลี่ยน filter (โรค/ภูมิภาค/ช่วงวันที่) ค่า KPI ทั้ง 4 ต้องคำนวณใหม่ให้ตรงกับ filter ที่เลือกทันที

## FR-DASH-03 — Region Risk Grid

**Given** ผู้ใช้อยู่ที่หน้า Outbreak Dashboard
**When** ผู้ใช้ดู Region Risk Grid หรือเปลี่ยน filter ภูมิภาค/ช่วงวันที่
**Then** ต้องแสดงครบ 6 ภาค (เหนือ/กลาง/อีสาน/ใต้/ตะวันออก/ตะวันตก) เสมอ พร้อมสีที่สะท้อนระดับความเสี่ยงจริงตาม legend และตอบสนองต่อ filter อย่างถูกต้อง

- [ ] แสดงครบ 6 ภาคเสมอ พร้อมชื่อภาค จำนวนเคสสะสม และจังหวัดศูนย์กลาง
- [ ] สีของแต่ละ cell ตรงกับ legend 3 ระดับ (ปกติ/เฝ้าระวัง/วิกฤต) เท่านั้น
- [ ] เมื่อเลือก filter ภูมิภาคเป็นภูมิภาคเดียว cell ของภูมิภาคอื่นต้อง**จางลง (dim)** แต่ยังคงแสดงอยู่ครบ 6 cell — **ไม่ใช่การซ่อน/ลบ cell ที่ไม่ตรงเงื่อนไข**
- [ ] จำนวนเคสที่แสดงในแต่ละ cell เปลี่ยนตามช่วงวันที่ที่เลือก (7/14/30 วัน) และ subtitle ของ panel ระบุช่วงเวลาที่ตรงกัน

## FR-DASH-04 — Trend Chart

**Given** ผู้ใช้อยู่ที่หน้า Outbreak Dashboard
**When** หน้าโหลดเสร็จ หรือผู้ใช้เปลี่ยน filter โรค/ภูมิภาค/ช่วงวันที่
**Then** กราฟแนวโน้มเคสรายวัน (แท่ง) พร้อมเส้นค่าเฉลี่ยเคลื่อนที่ 3 วันต้องแสดงจำนวนวันตรงกับช่วงเวลาที่เลือก และ subtitle ต้องสะท้อน filter ปัจจุบันทั้งหมด

- [ ] จำนวนแท่งกราฟเท่ากับจำนวนวันของช่วงเวลาที่เลือก (7/14/30 วัน)
- [ ] เส้นค่าเฉลี่ยเคลื่อนที่ 3 วันแสดงทับบนกราฟแท่ง พร้อม legend อธิบายทั้งแท่งและเส้นถูกต้อง
- [ ] Subtitle ของ panel แสดงชื่อโรค · ชื่อภูมิภาค · จำนวนวัน ตรงกับ filter ที่เลือกอยู่ ณ ขณะนั้น
- [ ] แม้เลือกชุด filter ที่มีจำนวนเคสต่ำมาก (เช่น อาหารเป็นพิษ + ภาคตะวันตก) กราฟยังคงเรนเดอร์ได้ปกติ ไม่มีแท่งหายหรือ error

## FR-DASH-05 — Recent Alerts Panel

**Given** ผู้ใช้อยู่ที่หน้า Outbreak Dashboard ที่มี mock alert 8 รายการ
**When** หน้าโหลดเสร็จ หรือผู้ใช้เปลี่ยน filter โรค/ภูมิภาค/ช่วงวันที่
**Then** รายการแจ้งเตือนที่แสดงต้องตรงกับเงื่อนไข filter ปัจจุบันเท่านั้น พร้อม severity badge/ชื่อโรค/พื้นที่/เวลาที่ถูกต้อง และต้องมี empty state เมื่อไม่มีรายการตรงเงื่อนไข

- [ ] แต่ละรายการแสดง severity badge ("วิกฤต" สำหรับ danger, "เฝ้าระวัง" สำหรับ warning) ตรงกับข้อมูลจริง พร้อมชื่อโรค พื้นที่ และเวลาที่ผ่านมา
- [ ] เมื่อเปลี่ยน filter โรค/ภูมิภาค/ช่วงวันที่ รายการที่แสดงต้องกรองเฉพาะรายการที่ตรงเงื่อนไขทั้งหมดพร้อมกัน (AND ไม่ใช่ OR)
- [ ] เมื่อไม่มีรายการใดตรงเงื่อนไข ต้องแสดงข้อความ empty state "ไม่พบการแจ้งเตือนตามเงื่อนไขตัวกรองที่เลือก" แทนพื้นที่ว่างเปล่า
- [ ] รูปแบบเวลาแสดงถูกต้องตามค่าจริง ("X ชั่วโมงที่แล้ว" เมื่อ < 24 ชม., "X วันที่แล้ว" เมื่อ ≥ 24 ชม.)

## FR-DASH-06 — Filter (โรค / ภูมิภาค / ช่วงวันที่ / ล้างตัวกรอง)

**Given** ผู้ใช้อยู่ที่หน้า Outbreak Dashboard ที่มี mock data ครบทุกภูมิภาค/โรค
**When** ผู้ใช้เลือกค่าใน dropdown โรค, ภูมิภาค, หรือช่วงวันที่ (เดี่ยวๆ หรือพร้อมกันหลายตัว) หรือกดปุ่ม "ล้างตัวกรอง"
**Then** KPI cards, Region Risk Grid, Trend Chart, และ Recent Alerts Panel ต้องอัปเดตให้สอดคล้องกันตามเงื่อนไข filter ที่เลือกทั้งหมด และปุ่มล้างตัวกรองต้องคืนค่าทุก dropdown กลับสู่ค่าเริ่มต้น

- [ ] Dropdown โรคมีตัวเลือกครบ 6 รายการ (รวม "ทุกโรค (All Diseases)" เป็นค่าเริ่มต้น)
- [ ] Dropdown ภูมิภาคมีตัวเลือกครบ 7 รายการ (รวม "ทุกภูมิภาค (All Regions)" เป็นค่าเริ่มต้น)
- [ ] Dropdown ช่วงวันที่มีตัวเลือกครบ 3 รายการ (7/14/30 วัน, ค่าเริ่มต้น 14 วัน)
- [ ] เมื่อเลือก filter หลายตัวพร้อมกัน ทั้ง 4 ส่วนของ dashboard (KPI/Region Grid/Chart/Alerts) ต้องกรองตรงกันแบบ AND ไม่มีส่วนใดค้างค่าเก่า
- [ ] ปุ่ม "ล้างตัวกรอง" คืนค่า dropdown ทั้ง 3 กลับเป็นค่าเริ่มต้นและ re-render ข้อมูลทั้งหมดให้ตรงกับสถานะเริ่มต้น
