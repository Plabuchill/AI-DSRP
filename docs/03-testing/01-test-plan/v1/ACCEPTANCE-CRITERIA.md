## FR-DASH-01 — Navigation (Left Rail)

**Given** ผู้ใช้เปิดหน้า Outbreak Dashboard ครั้งแรก
**When** ผู้ใช้มองไปที่แถบเมนูซ้าย (left rail)
**Then** ต้องเห็น wordmark "ai-dsrp", หน้า Dashboard ต้องถูกทำเครื่องหมายว่าเป็นหน้าที่ active อยู่ และเมนู Cases/Alerts/Reports ต้องแสดงเป็น placeholder ที่ปิดใช้งาน (ไม่สามารถคลิกนำทางได้)

- [ ] Wordmark "ai-dsrp" แสดงที่ด้านบนของ left rail
- [ ] เมนู "Dashboard" มี state active แตกต่างจากเมนูอื่นอย่างชัดเจน
- [ ] เมนู Cases / Alerts / Reports แสดง badge "SOON" และ aria-disabled="true" คลิกแล้วไม่มีการนำทางใดๆ เกิดขึ้น
- [ ] บนหน้าจอ tablet (≤960px) left rail ยุบเหลือ icon-only (short mark "ai") โดยไม่กระทบการใช้งานเมนู Dashboard

## FR-DASH-02 — Stat Tiles

> **อัปเดต 2026-08-23**: เดิมเป็น "KPI Cards" 4 การ์ด (Total Active Cases/New Cases Today/Active Outbreak Zones/Overall Risk Level) — ปรับให้ตรงกับ implementation ปัจจุบัน (`prototypes/v1/index.html` `.stat-tile-grid`, `prototypes/v1/script.js` `renderStatTiles()`) เป็น 5 การ์ด ("Stat Tiles") ไม่เปลี่ยนเลข FR-DASH-02/FEAT-DASH-02

**Given** ผู้ใช้อยู่ที่หน้า Outbreak Dashboard ที่มี mock data ครบทุกเขตบริการ/โรค
**When** หน้าโหลดเสร็จ (ค่าเริ่มต้น: ทุกโรค/ทุกเขตบริการ/14 วัน) หรือผู้ใช้เปลี่ยน filter ใดๆ
**Then** Stat Tiles ทั้ง 5 การ์ด (รายใหม่วันนี้, รายใหม่นอกพื้นที่, ในพื้นที่สะสม, นอกพื้นที่สะสม, รวมผู้ป่วยสะสม) ต้องแสดงค่าที่คำนวณจากข้อมูลที่ตรงกับ filter ปัจจุบันเสมอ ไม่ค้างค่าเดิมหรือแสดง "--" โดยพื้นหลังของแต่ละการ์ดใช้โทนดินอ่อนแยกตามหมวด (tone-accent-tint/tone-secondary-tint/tone-primary-tint) ไม่ใช่สีสถานะความเสี่ยง

- [ ] ทั้ง 5 การ์ดแสดงค่าตัวเลขจริงหลังโหลดหน้า (ไม่ใช่ "--"): รายใหม่วันนี้, รายใหม่นอกพื้นที่, ในพื้นที่สะสม, นอกพื้นที่สะสม, รวมผู้ป่วยสะสม
- [ ] พื้นหลังของการ์ดใช้โทนดินอ่อนแยกตามหมวด (accent/secondary/primary tint) เท่านั้น ไม่มีการ์ดใดใช้สีสถานะความเสี่ยง (เขียว/เหลือง/แดง) แบบ Zone Risk Grid
- [ ] "ในพื้นที่สะสม" + "นอกพื้นที่สะสม" ต้องรวมกันเท่ากับ "รวมผู้ป่วยสะสม" พอดีเสมอ (ไม่มีเคสตกหล่นหรือซ้ำ)
- [ ] เมื่อเปลี่ยน filter (โรค/เขตบริการ/ช่วงวันที่) ค่าทั้ง 5 การ์ดต้องคำนวณใหม่ให้ตรงกับ filter ที่เลือกทันที

## FR-DASH-03 — Zone Risk Grid

**Given** ผู้ใช้อยู่ที่หน้า Outbreak Dashboard
**When** ผู้ใช้ดู Zone Risk Grid หรือเปลี่ยน filter เขตบริการ/ช่วงวันที่
**Then** ต้องแสดงครบ 4 เขตบริการ (เขตบริการ 1-4 ครอบคลุมชุมชนย่อยรวม 63 ชุมชน) เสมอ พร้อมสีที่สะท้อนระดับความเสี่ยงจริงตาม legend, ตอบสนองต่อ filter อย่างถูกต้อง, และให้ผู้ใช้ขยายดูรายชื่อชุมชน/ทีมสอบสวนโรคที่รับผิดชอบในแต่ละเขตได้

- [ ] แสดงครบ 4 เขตบริการเสมอ พร้อมชื่อเขต จำนวนเคสสะสม และจำนวนชุมชนในเขต (ไม่มีป้าย "จังหวัดศูนย์กลาง" อีกต่อไป เพราะทุกเขตอยู่ในเทศบาลเดียวกัน)
- [ ] สีของแต่ละ cell ตรงกับ legend 3 ระดับ (ปกติ/เฝ้าระวัง/วิกฤต) เท่านั้น
- [ ] เมื่อเลือก filter เขตบริการเป็นเขตเดียว cell ของเขตอื่นต้อง**จางลง (dim)** แต่ยังคงแสดงอยู่ครบ 4 cell — **ไม่ใช่การซ่อน/ลบ cell ที่ไม่ตรงเงื่อนไข**
- [ ] จำนวนเคสที่แสดงในแต่ละ cell เปลี่ยนตามช่วงวันที่ที่เลือก (7/14/30 วัน) และ subtitle ของ panel ระบุช่วงเวลาที่ตรงกัน
- [ ] คลิกปุ่ม "ดูรายชื่อชุมชน" ในแต่ละ cell แล้วขยาย (accordion) แสดงรายชื่อชุมชนทั้งหมดในเขตนั้น พร้อม badge ทีมสอบสวนโรค ("ทีมสอบสวนโรค เขต N") รับผิดชอบต่อชุมชน — ไม่มีตัวเลขเคสแยกรายชุมชน (ข้อมูลอ้างอิงเท่านั้น) และคลิกซ้ำ (หรือปุ่ม "ซ่อนรายชื่อชุมชน") เพื่อยุบกลับได้

## FR-DASH-04 — Trend Chart (รายวัน + รายสัปดาห์)

> **อัปเดต 2026-08-23**: เดิมมีเฉพาะกราฟรายวัน — เพิ่มกราฟแนวโน้มรายสัปดาห์ทั้งปี (52 สัปดาห์) เทียบค่ามัธยฐานปีก่อน แสดง**คู่กัน**กับกราฟรายวันเดิม (`prototypes/v1/script.js` `renderChart()` + `renderWeeklyChart()`) ไม่เปลี่ยนเลข FR-DASH-04/FEAT-DASH-04

**Given** ผู้ใช้อยู่ที่หน้า Outbreak Dashboard
**When** หน้าโหลดเสร็จ หรือผู้ใช้เปลี่ยน filter โรค/เขตบริการ/ช่วงวันที่
**Then** ต้องแสดง 2 กราฟคู่กัน: (1) กราฟแนวโน้มเคสรายวัน (แท่ง) พร้อมเส้นค่าเฉลี่ยเคลื่อนที่ 3 วัน ที่จำนวนวันตรงกับช่วงเวลาที่เลือก (7/14/30 วัน) และ (2) กราฟแนวโน้มรายสัปดาห์ทั้งปี (52 สัปดาห์) เทียบค่ามัธยฐานปีก่อน ซึ่ง**ไม่ผูกกับ filter ช่วงวันที่** (แสดงครบ 52 สัปดาห์เสมอ ไม่ว่าจะเลือก 7/14/30 วัน) แต่ยังกรองตามโรค/เขตบริการเหมือนกราฟรายวัน — subtitle ของทั้ง 2 panel ต้องสะท้อน filter ปัจจุบันและแยกแยะกันชัดเจน

- [ ] กราฟรายวัน: จำนวนแท่งเท่ากับจำนวนวันของช่วงเวลาที่เลือก (7/14/30 วัน) พร้อมเส้นค่าเฉลี่ยเคลื่อนที่ 3 วันแสดงทับบนกราฟแท่ง
- [ ] กราฟรายสัปดาห์: แสดงครบ 52 สัปดาห์เสมอ (เส้นปีปัจจุบันเทียบเส้นค่ามัธยฐานปีก่อน) ไม่เปลี่ยนแปลงตามตัวกรองช่วงวันที่ (7/14/30 วัน) — เปลี่ยนได้เฉพาะตาม filter โรค/เขตบริการ
- [ ] Subtitle ของกราฟรายวันแสดงชื่อโรค · ชื่อเขตบริการ · จำนวนวัน ส่วน subtitle ของกราฟรายสัปดาห์แสดงชื่อโรค · ชื่อเขตบริการ · "รายสัปดาห์ทั้งปี (52 สัปดาห์)" — ต้องตรงกับ filter ที่เลือกอยู่ ณ ขณะนั้นและไม่สับสนกับกราฟรายวัน
- [ ] Legend ของกราฟรายสัปดาห์ระบุ "ปีปัจจุบัน (พ.ศ. ปีปัจจุบัน)" และ "ค่ามัธยฐานปีก่อน (พ.ศ. ปีก่อน)" ให้ตรงกับปีจริงตามวันที่ mock
- [ ] แม้เลือกชุด filter ที่มีจำนวนเคสต่ำมาก (เช่น อาหารเป็นพิษ + เขตบริการ 1) ทั้ง 2 กราฟยังคงเรนเดอร์ได้ปกติ ไม่มีแท่ง/เส้นหายหรือ error

## FR-DASH-05 — Recent Alerts Panel

**Given** ผู้ใช้อยู่ที่หน้า Outbreak Dashboard ที่มี mock alert 8 รายการ
**When** หน้าโหลดเสร็จ หรือผู้ใช้เปลี่ยน filter โรค/เขตบริการ/ช่วงวันที่
**Then** รายการแจ้งเตือนที่แสดงต้องตรงกับเงื่อนไข filter ปัจจุบันเท่านั้น พร้อม severity badge/ชื่อโรค/พื้นที่/เวลาที่ถูกต้อง และต้องมี empty state เมื่อไม่มีรายการตรงเงื่อนไข

- [ ] แต่ละรายการแสดง severity badge ("วิกฤต" สำหรับ danger, "เฝ้าระวัง" สำหรับ warning) ตรงกับข้อมูลจริง พร้อมชื่อโรค เขตบริการ/ชุมชน และเวลาที่ผ่านมา
- [ ] เมื่อเปลี่ยน filter โรค/เขตบริการ/ช่วงวันที่ รายการที่แสดงต้องกรองเฉพาะรายการที่ตรงเงื่อนไขทั้งหมดพร้อมกัน (AND ไม่ใช่ OR)
- [ ] เมื่อไม่มีรายการใดตรงเงื่อนไข ต้องแสดงข้อความ empty state "ไม่พบการแจ้งเตือนตามเงื่อนไขตัวกรองที่เลือก" แทนพื้นที่ว่างเปล่า
- [ ] รูปแบบเวลาแสดงถูกต้องตามค่าจริง ("X ชั่วโมงที่แล้ว" เมื่อ < 24 ชม., "X วันที่แล้ว" เมื่อ ≥ 24 ชม.)

## FR-DASH-06 — Filter (โรค / เขตบริการ / ช่วงวันที่ / ล้างตัวกรอง)

**Given** ผู้ใช้อยู่ที่หน้า Outbreak Dashboard ที่มี mock data ครบทุกเขตบริการ/โรค
**When** ผู้ใช้เลือกค่าใน dropdown โรค, เขตบริการ, หรือช่วงวันที่ (เดี่ยวๆ หรือพร้อมกันหลายตัว) หรือกดปุ่ม "ล้างตัวกรอง"
**Then** KPI cards, Zone Risk Grid, Trend Chart, และ Recent Alerts Panel ต้องอัปเดตให้สอดคล้องกันตามเงื่อนไข filter ที่เลือกทั้งหมด และปุ่มล้างตัวกรองต้องคืนค่าทุก dropdown กลับสู่ค่าเริ่มต้น

- [ ] Dropdown โรคมีตัวเลือกครบ 6 รายการ (รวม "ทุกโรค (All Diseases)" เป็นค่าเริ่มต้น)
- [ ] Dropdown เขตบริการมีตัวเลือกครบ 5 รายการ (รวม "ทุกเขตบริการ (All Zones)" เป็นค่าเริ่มต้น)
- [ ] Dropdown ช่วงวันที่มีตัวเลือกครบ 3 รายการ (7/14/30 วัน, ค่าเริ่มต้น 14 วัน)
- [ ] เมื่อเลือก filter หลายตัวพร้อมกัน ทั้ง 4 ส่วนของ dashboard (KPI/Zone Grid/Chart/Alerts) ต้องกรองตรงกันแบบ AND ไม่มีส่วนใดค้างค่าเก่า
- [ ] ปุ่ม "ล้างตัวกรอง" คืนค่า dropdown ทั้ง 3 กลับเป็นค่าเริ่มต้นและ re-render ข้อมูลทั้งหมดให้ตรงกับสถานะเริ่มต้น

> **เพิ่ม 2026-08-23**: `FR-DASH-07` ถึง `15` ต่อจากนี้ ตรงกับ `FEAT-DASH-07` ถึง `15` ใน [Feature List](../../../01-requirements/01-spec/FEATURE-LIST.md) แบบ 1:1 (panel วิเคราะห์เชิงลึกที่เพิ่มเข้ามาใหม่ในหน้า Outbreak Dashboard เดียวกัน) — อ้างอิงจากการอ่านโค้ดจริงใน `prototypes/v1/index.html`/`prototypes/v1/script.js`

## FR-DASH-07 — อัตราป่วยต่อแสนประชากร

**Given** ผู้ใช้อยู่ที่หน้า Outbreak Dashboard ที่มี mock population ต่อเขตบริการ (`ZONES[].population`)
**When** หน้าโหลดเสร็จ หรือผู้ใช้เปลี่ยน filter โรค/เขตบริการ/ช่วงวันที่
**Then** การ์ดอัตราป่วยต่อแสนประชากรต้องคำนวณจาก (เคสสะสมในช่วงที่กรอง ÷ ประชากรฐานรวมของเขตบริการที่กรอง) × 100,000 และอัปเดตทันทีตาม filter ที่เลือก

- [ ] ค่าที่แสดงตรงกับสูตร (เคสสะสมตาม filter ปัจจุบัน ÷ ประชากรฐานของเขตบริการที่กรอง) × 100,000
- [ ] เมื่อเลือกเขตบริการเดียว ตัวหาร (ประชากรฐาน) ต้องเปลี่ยนเป็นประชากรของเขตนั้นเขตเดียว ไม่ใช่ประชากรรวมทั้ง 4 เขต
- [ ] เมื่อเปลี่ยนช่วงวันที่ (7/14/30 วัน) ตัวเศษ (เคสสะสม) ต้องเปลี่ยนตามช่วงที่เลือก
- [ ] ข้อความอธิบายใต้การ์ด (ประชากรฐาน/เคสสะสม/ช่วงวันที่) ต้องตรงกับตัวเลขที่ใช้คำนวณจริง

## FR-DASH-08 — ตารางแยกตามเพศ

**Given** ผู้ใช้อยู่ที่หน้า Outbreak Dashboard ที่มี mock data ครบทุกเขตบริการ/โรค
**When** หน้าโหลดเสร็จ หรือผู้ใช้เปลี่ยน filter โรค/เขตบริการ/ช่วงวันที่
**Then** ตารางต้องแสดง 2 แถว (ชาย/หญิง) พร้อมจำนวนเคส/ร้อยละ/progress bar สัดส่วนที่ตรงกับ filter ปัจจุบัน โดยร้อยละของทั้ง 2 แถวรวมกันต้อง ≈100% เสมอ

- [ ] แสดงครบ 2 แถว (ชาย, หญิง) พร้อมจำนวนเคสที่รวมกันเท่ากับจำนวนเคสสะสมรวมของ filter ปัจจุบันพอดี
- [ ] ร้อยละของแต่ละแถวคำนวณถูกต้อง (จำนวนเคสแถวนั้น ÷ รวมทั้งหมด × 100) และผลรวมร้อยละ ≈100% (คลาดเคลื่อนจากการปัดเศษได้ไม่เกิน ±0.2%)
- [ ] Progress bar (`.cluster-confidence-fill`) ของแต่ละแถวยาวตามสัดส่วนร้อยละที่ถูกต้อง
- [ ] เมื่อเปลี่ยน filter ตัวเลข/ร้อยละ/progress bar ต้องอัปเดตพร้อมกันทั้ง 2 แถว

## FR-DASH-09 — ตารางกลุ่มอายุ

**Given** ผู้ใช้อยู่ที่หน้า Outbreak Dashboard ที่มี mock data ครบทุกเขตบริการ/โรค
**When** หน้าโหลดเสร็จ หรือผู้ใช้เปลี่ยน filter โรค/เขตบริการ/ช่วงวันที่
**Then** ตารางต้องแสดงครบ 5 ช่วงอายุ (05-14, 15-24, 25-34, 35-44, 45-54) พร้อมจำนวนเคส/ร้อยละ/อัตราป่วยต่อแสนปกครองต่อช่วงอายุ โดยร้อยละรวมของทั้ง 5 ช่วงต้อง ≈100%

- [ ] แสดงครบ 5 ช่วงอายุตามลำดับที่กำหนด (05-14, 15-24, 25-34, 35-44, 45-54) ไม่ขาด/สลับลำดับ
- [ ] ร้อยละของแต่ละช่วงคำนวณจากจำนวนเคสช่วงนั้น ÷ รวมทั้งหมด × 100 และผลรวมร้อยละ ≈100%
- [ ] อัตราป่วยต่อแสนปกครองต่อช่วงอายุคำนวณแยกจากประชากรฐานของช่วงอายุนั้นโดยเฉพาะ (คนละสูตรจากคอลัมน์ร้อยละ) ไม่ใช่ค่าเดียวกับ FR-DASH-07
- [ ] เมื่อเปลี่ยน filter โรค/เขตบริการ/ช่วงวันที่ ตัวเลขทั้ง 3 คอลัมน์ (จำนวนเคส/ร้อยละ/อัตราป่วยต่อแสน) ต้องอัปเดตพร้อมกัน

## FR-DASH-10 — สถิติอายุผู้ป่วย

**Given** ผู้ใช้อยู่ที่หน้า Outbreak Dashboard ที่มี mock data ครบทุกเขตบริการ/โรค
**When** หน้าโหลดเสร็จ หรือผู้ใช้เปลี่ยน filter โรค/เขตบริการ/ช่วงวันที่
**Then** การ์ดอายุมากที่สุด/มัธยฐาน/น้อยที่สุด ต้องคำนวณจากเฉพาะกลุ่มเคสที่ตรงกับ filter ปัจจุบันเท่านั้น (สอดคล้องกับข้อมูลชุดเดียวกับตารางกลุ่มอายุ FR-DASH-09)

- [ ] อายุมากที่สุด = ค่าอายุสูงสุดในกลุ่มเคสที่ตรง filter ปัจจุบัน
- [ ] อายุน้อยที่สุด = ค่าอายุต่ำสุดในกลุ่มเดียวกัน
- [ ] อายุมัธยฐานคำนวณถูกต้องทั้งกรณีจำนวนเคสเป็นเลขคี่ (ค่ากลาง) และเลขคู่ (เฉลี่ย 2 ค่ากลาง)
- [ ] เมื่อเปลี่ยน filter ค่าทั้ง 3 (มากที่สุด/มัธยฐาน/น้อยที่สุด) ต้องคำนวณใหม่จากกลุ่มเคสที่กรองแล้วเท่านั้น และแสดง "-" เมื่อไม่มีเคสตรงเงื่อนไขเลย (ไม่ error/ไม่ค้างค่าเดิม)

## FR-DASH-11 — การวินิจฉัยโรค (DF/DHF)

> **Edge case สำคัญที่สุดของรอบนี้**: panel นี้ต้อง**แสดงเฉพาะเมื่อ filter โรค = "ไข้เลือดออก (Dengue Fever)" เท่านั้น** — เมื่อเลือกโรคอื่นหรือ "ทุกโรค" panel ต้องถูกซ่อนและแสดง note แทน (`prototypes/v1/script.js` `renderDiagnosisPie()`, ข้อความ note ที่ `#diagnosis-pie-note`: "แสดงเมื่อเลือกตัวกรองโรคเป็นไข้เลือดออก (Dengue Fever) เท่านั้น")

**Given** ผู้ใช้อยู่ที่หน้า Outbreak Dashboard
**When** ผู้ใช้เลือก filter โรคเป็น "ไข้เลือดออก (Dengue Fever)" หรือเลือกเป็นโรคอื่น/ทุกโรค
**Then** Donut chart สัดส่วน DF/DHF ต้องแสดงเฉพาะกรณี filter โรค = ไข้เลือดออกเท่านั้น กรณีอื่นทั้งหมดต้องซ่อน donut chart + legend และแสดง note แทน

- [ ] เมื่อ filter โรค = "ไข้เลือดออก (Dengue Fever)" panel Donut chart + legend แสดงสัดส่วน DF (ไข้เดงกี)/DHF (ไข้เลือดออกช็อก) ที่ตรงกับข้อมูลตาม filter เขตบริการ/ช่วงวันที่ปัจจุบัน และ note ต้องซ่อน
- [ ] เมื่อ filter โรค = "ทุกโรค (All Diseases)" panel donut chart + legend ต้องซ่อน และแสดง note "แสดงเมื่อเลือกตัวกรองโรคเป็นไข้เลือดออก (Dengue Fever) เท่านั้น" แทน
- [ ] เมื่อ filter โรคเป็นโรคอื่นที่ไม่ใช่ไข้เลือดออก (เช่น ไข้หวัดใหญ่, โควิด-19, HFMD, อาหารเป็นพิษ) panel ต้องซ่อนเช่นเดียวกันและแสดง note เดียวกัน
- [ ] สัดส่วน DF + DHF ในโดนัทชาร์ต (เมื่อแสดง) ต้องรวมกันเท่ากับจำนวนเคสไข้เลือดออกทั้งหมดที่ตรงกับ filter เขตบริการ/ช่วงวันที่ปัจจุบันพอดี (ไม่มีเคสตกหล่น)

## FR-DASH-12 — ตารางอาชีพ

**Given** ผู้ใช้อยู่ที่หน้า Outbreak Dashboard ที่มี mock data ครบทุกเขตบริการ/โรค
**When** หน้าโหลดเสร็จ หรือผู้ใช้เปลี่ยน filter โรค/เขตบริการ/ช่วงวันที่
**Then** ตารางต้องแสดงจำนวนเคส/ร้อยละแยกตามหมวดอาชีพครบ 5 หมวด (รับจ้าง, นักเรียน/นักศึกษา, ค้าขาย, ทหาร/ตำรวจ, อื่นๆ) โดยร้อยละรวมต้อง ≈100%

- [ ] แสดงครบ 5 หมวดอาชีพตามที่กำหนด (รับจ้าง, นักเรียน/นักศึกษา, ค้าขาย, ทหาร/ตำรวจ, อื่นๆ) ไม่ขาดหมวดใด
- [ ] จำนวนเคสรวมของทั้ง 5 หมวดเท่ากับจำนวนเคสสะสมรวมของ filter ปัจจุบันพอดี (ไม่มีเคสตกหล่น)
- [ ] ร้อยละของแต่ละหมวดคำนวณถูกต้องและผลรวม ≈100%
- [ ] เมื่อเปลี่ยน filter ตัวเลข/ร้อยละของทั้ง 5 หมวดต้องอัปเดตให้ตรงกับกลุ่มเคสที่กรองแล้ว

## FR-DASH-13 — ตารางชุมชนที่มีจำนวนเคสสูงสุด

**Given** ผู้ใช้อยู่ที่หน้า Outbreak Dashboard ที่มี mock data ครบ 63 ชุมชนใน 4 เขตบริการ
**When** หน้าโหลดเสร็จ หรือผู้ใช้เปลี่ยน filter โรค/เขตบริการ/ช่วงวันที่
**Then** ตารางต้องแสดง Top 8 ชุมชนตามจำนวนเคสสะสมมากไปน้อย พร้อมเขตบริการ/ทีมสอบสวนโรค/ร้อยละ โดยผลรวมจำนวนเคสของชุมชนที่แสดงต้องไม่เกินยอดรวมระดับเขตบริการ (หรือยอดรวมทุกเขตที่กรอง) ที่ชุมชนเหล่านั้นสังกัด

- [ ] แสดงไม่เกิน 8 แถว เรียงจากจำนวนเคสมากไปน้อย และแสดง empty state ("ไม่มีข้อมูลเคสตามเงื่อนไขตัวกรองที่เลือก") เมื่อไม่มีชุมชนใดตรงเงื่อนไข
- [ ] แต่ละแถวระบุเขตบริการ/badge ทีมสอบสวนโรคที่รับผิดชอบถูกต้อง ตรงกับข้อมูลเขต/ทีมใน Zone Risk Grid (FR-DASH-03)
- [ ] ผลรวมจำนวนเคสของชุมชนทั้งหมดที่แสดงในตารางนี้ต้องไม่เกินจำนวนเคสสะสมรวมของเขตบริการ (หรือทุกเขตที่กรองรวมกัน) ที่แสดงใน Zone Risk Grid/Stat Tiles ณ filter เดียวกัน
- [ ] ร้อยละของแต่ละชุมชนคำนวณจากจำนวนเคสชุมชนนั้น ÷ ยอดรวมเคสทั้งหมดของเขตบริการที่กรอง (ไม่ใช่ยอดรวมเฉพาะ 8 แถวที่แสดง — ร้อยละของ 8 แถวที่แสดงจึงไม่จำเป็นต้องรวมกันเป็น 100%)
- [ ] เมื่อเปลี่ยน filter รายชื่อ Top 8 และลำดับต้องคำนวณใหม่ให้ตรงกับข้อมูลที่กรอง

## FR-DASH-14 — ตารางเขตบริการเรียงตามอัตราป่วย

**Given** ผู้ใช้อยู่ที่หน้า Outbreak Dashboard ที่มี mock population ต่อเขตบริการ
**When** หน้าโหลดเสร็จ หรือผู้ใช้เปลี่ยน filter โรค/เขตบริการ/ช่วงวันที่
**Then** ตารางต้องแสดงเขตบริการที่ตรงกับ filter เขตบริการปัจจุบัน (4 เขตเมื่อเลือก "ทุกเขตบริการ" หรือเฉพาะเขตเดียวเมื่อเลือกเขตนั้น) พร้อมจำนวนเคส/ประชากร/อัตราป่วยต่อแสนประชากร **เรียงจากอัตราป่วยสูงไปต่ำเสมอ**

- [ ] เมื่อเลือก "ทุกเขตบริการ" ตารางแสดงครบ 4 เขต พร้อมจำนวนเคส/ประชากร/อัตราป่วยต่อแสนประชากรที่คำนวณถูกต้อง (สูตรเดียวกับ FR-DASH-07 แต่แยกคำนวณรายเขต)
- [ ] แถวเรียงจากอัตราป่วยต่อแสนประชากรสูงไปต่ำเสมอ ไม่ว่า filter โรค/ช่วงวันที่จะเป็นค่าใด (ต้องทดสอบว่าลำดับเปลี่ยนถูกต้องเมื่อเปลี่ยน filter)
- [ ] เมื่อเลือก filter เขตบริการเป็นเขตเดียว ตารางแสดงเฉพาะเขตนั้นเขตเดียว (กรองแถวออก ไม่ใช่ dim เหมือน Zone Risk Grid FR-DASH-03 — พฤติกรรมต่างจาก FR-DASH-03 โดยตั้งใจ)
- [ ] เมื่อเปลี่ยน filter โรค/ช่วงวันที่ ตัวเลขจำนวนเคส/อัตราป่วยและลำดับการเรียงต้องคำนวณใหม่ทั้งหมด (re-sort จริง ไม่ใช่แค่อัปเดตตัวเลขแต่คงลำดับเดิม)

## FR-DASH-15 — ตารางป่วยจาก

**Given** ผู้ใช้อยู่ที่หน้า Outbreak Dashboard ที่มี mock data ครบทุกเขตบริการ/โรค
**When** หน้าโหลดเสร็จ หรือผู้ใช้เปลี่ยน filter โรค/เขตบริการ/ช่วงวันที่
**Then** ตารางต้องแสดง 2 แถว ("เริ่มป่วยจากนอกพื้นที่ (สะสม)" และ "รายใหม่ไม่อยู่ในพื้นที่เกิน 100 เมตร") พร้อมจำนวน/ร้อยละที่ตรงกับ filter ปัจจุบัน

- [ ] แถว "เริ่มป่วยจากนอกพื้นที่ (สะสม)" แสดงจำนวนเท่ากับ "นอกพื้นที่สะสม" ใน Stat Tiles (FR-DASH-02) พอดี พร้อมร้อยละเทียบกับเคสสะสมรวม
- [ ] แถว "รายใหม่ไม่อยู่ในพื้นที่เกิน 100 เมตร" แสดงจำนวนและร้อยละเทียบกับ "รายใหม่วันนี้" (ไม่ใช่เทียบกับเคสสะสมรวม)
- [ ] ตัวเลขทั้ง 2 แถวต้องไม่ติดลบและไม่เกินฐานที่ใช้เทียบ (แถวแรกไม่เกินเคสสะสมรวม, แถวสองไม่เกินรายใหม่วันนี้)
- [ ] เมื่อเปลี่ยน filter โรค/เขตบริการ/ช่วงวันที่ ตัวเลขทั้ง 2 แถวต้องอัปเดตให้ตรงกับ Stat Tiles ที่คำนวณจาก filter เดียวกัน
